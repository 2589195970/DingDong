# 叮咚号卡商品照片上传与审核功能设计方案

## 功能概述

### 需求背景
针对特定号卡商品，需要增加身份验证照片上传和审核机制，确保下单用户身份真实性，提升合规性和安全性。

### 功能目标
1. **商品配置灵活化**：支持为不同商品配置是否需要照片上传要求
2. **上传流程便捷化**：用户在下单时根据商品要求上传相应照片
3. **审核流程规范化**：代理商维护照片，管理员统一审核
4. **状态管理透明化**：基于现有订单状态机制，无缝集成照片审核流程

## 一、数据库设计方案

### 3. 审核日志机制

利用现有的订单状态变更记录机制，照片审核的状态变更将记录在现有的订单操作日志中，无需单独创建照片审核日志表。

## 二、基于现有订单状态的设计

### 1. 订单状态扩展

基于现有的 `OrderEnum`，照片审核作为订单状态的一个子状态：

```java
// 现有订单状态
public enum OrderEnum {
    INVALID(-1, "订单失败"),
    CREATE(0, "订单预创建"),
    APPLY(1, "订单申请成功"),
    SHIPPED(2, "订单已发货"),
    RECEIVED(3, "订单已签收"),
    ACTIVATED(4, "订单已激活");

    // 新增照片审核状态
    // 当商品需要照片审核时，订单状态为 APPLY(1) "订单申请成功"
    // 同时 photo_status 表示照片审核进度
}

// 照片审核状态枚举
public enum PhotoAuditEnum {
    NONE(0, "无需审核"),
    PENDING(1, "待审核"),
    APPROVED(2, "审核通过"),
    REJECTED(3, "审核拒绝");

    private Integer status;
    private String message;
}
```

### 2. 状态流转逻辑

```
订单创建 → APPLY(1) + photo_status=PENDING(1) → 等待照片审核
        ↓ 管理员审核通过
        ↓
        APPLY(1) + photo_status=APPROVED(2) → 进入正常订单流程
        ↓ 管理员审核拒绝
        ↓
        APPLY(1) + photo_status=REJECTED(3) → 重新上传照片
```

```javascript
// 照片配置
const photoConfigList = ref({});
const photos = ref({});

// 获取商品照片配置
const getProductPhotoConfig = async (productCode) => {
  try {
    const response = await axios.get(`/product/getProductPhotoConfig?productId=${productId}`);
    photoConfigList.value = response.data.photoConfig || {};
  } catch (error) {
    console.error('获取照片配置失败:', error);
  }
};

// 选择照片
const selectPhoto = (type) => {
  const fileInput = document.getElementById(`fileInput_${type}`);
  fileInput.click();
};

// 处理文件选择
const handleFileChange = async (event, type) => {
  const file = event.target.files[0];
  if (!file) return;

  // 文件大小限制
  if (file.size > 5 * 1024 * 1024) {
    vant.Toast('文件大小不能超过5MB');
    return;
  }

  // 文件类型检查
  if (!file.type.startsWith('image/')) {
    vant.Toast('请选择图片文件');
    return;
  }

  try {
    const formData = new FormData();
    formData.append('file', file);
    formData.append('orderId', orderId);
    formData.append('photoType', type);

    const response = await axios.post('/order/photo/upload', formData, {
      headers: {
        'Content-Type': 'multipart/form-data'
      }
    });

    photos.value[type] = response.data.photoUrl;
    vant.Toast('上传成功');
  } catch (error) {
    console.error('上传失败:', error);
    vant.Toast('上传失败，请重试');
  }
};

// 提交审核
const submitForAudit = async () => {
  // 验证必填照片
  const requiredPhotos = Object.entries(photoConfigList.value)
    .filter(([_, config]) => config.required)
    .map(([type, _]) => type);

  const missingPhotos = requiredPhotos.filter(type => !photos.value[type]);

  if (missingPhotos.length > 0) {
    const missingLabels = missingPhotos.map(type => photoConfigList.value[type].label).join('、');
    vant.Toast(`请上传：${missingLabels}`);
    return;
  }

  try {
    await axios.post('/order/photo/submitForAudit', {
      orderId: orderId,
      photos: photos.value
    });

    vant.Toast('提交成功，等待审核');
    // 跳转到订单详情页
    window.location.href = `/order/detail?orderId=${orderId}`;
  } catch (error) {
    console.error('提交失败:', error);
    vant.Toast('提交失败，请重试');
  }
};
```

#### 2.2 JavaScript 逻辑
```javascript
// 在现有Vue组件中增加照片相关方法
data() {
  return {
    // 现有数据...
    photoDialogVisible: false,
    currentOrder: null,
    currentPhotoType: 'idCardFront',
    currentOrderPhotoConfig: {}
  }
},

methods: {
  // 获取照片状态文本
  getPhotoStatusText(status) {
    const statusMap = {
      0: '无需审核',
      1: '待审核',
      2: '审核通过',
      3: '审核拒绝'
    };
    return statusMap[status] || '未知状态';
  },

  // 获取照片状态类型
  getPhotoStatusType(status) {
    const typeMap = {
      0: 'info',
      1: 'warning',
      2: 'success',
      3: 'danger'
    };
    return typeMap[status] || 'info';
  },

  // 管理照片
  async managePhotos(row) {
    this.currentOrder = row;
    // 获取商品照片配置
    try {
      const response = await this.$api.product.getProductPhotoConfig(row.productId);
      this.currentOrderPhotoConfig = response.data.photoConfig || {};
    } catch (error) {
      console.error('获取照片配置失败:', error);
    }

    this.photoDialogVisible = true;
    this.currentPhotoType = 'idCardFront';
  },

  // 重新上传照片
  reuploadPhoto() {
    const fileInput = document.createElement('input');
    fileInput.type = 'file';
    fileInput.accept = 'image/*';
    fileInput.onchange = async (event) => {
      const file = event.target.files[0];
      if (!file) return;

      try {
        const formData = new FormData();
        formData.append('file', file);
        formData.append('orderId', this.currentOrder.orderId);
        formData.append('photoType', this.currentPhotoType);

        const response = await this.$api.order.photo.upload(formData);

        // 更新当前订单数据
        await this.getList();

        this.$message.success('上传成功');
      } catch (error) {
        console.error('上传失败:', error);
        this.$message.error('上传失败，请重试');
      }
    };
    fileInput.click();
  },

  // 提交审核
  async submitForAudit() {
    try {
      await this.$api.order.photo.submitForAudit({
        orderId: this.currentOrder.orderId
      });

      this.$message.success('提交成功，等待审核');
      this.photoDialogVisible = false;
      this.getList();
    } catch (error) {
      console.error('提交失败:', error);
      this.$message.error('提交失败，请重试');
    }
  }
}

    approvePhoto(row) {
      this.auditDialog = {
        visible: true,
        title: '审核通过',
        currentOrder: row
      };
      this.auditForm = {
        orderId: row.orderId,
        photoStatus: 2,
        photoAuditRemark: ''
      };
    },

    rejectPhoto(row) {
      this.auditDialog = {
        visible: true,
        title: '审核拒绝',
        currentOrder: row
      };
      this.auditForm = {
        orderId: row.orderId,
        photoStatus: 3,
        photoAuditRemark: ''
      };
    },

    submitAudit() {
      if (this.auditForm.photoStatus === 3 && !this.auditForm.photoAuditRemark) {
        this.$message.warning('请输入审核拒绝原因');
        return;
      }

      this.$api.order.photo.audit.audit(this.auditForm)
        .then(() => {
          this.$message.success('审核成功');
          this.auditDialog.visible = false;
          this.getList();
        })
        .catch(error => {
          console.error('审核失败:', error);
          this.$message.error('审核失败，请重试');
        });
    },

    getStatusText(status) {
      const statusMap = {
        0: '无需审核',
        1: '待审核',
        2: '审核通过',
        3: '审核拒绝'
      };
      return statusMap[status] || '未知状态';
    },

    getStatusType(status) {
      const typeMap = {
        0: 'info',
        1: 'warning',
        2: 'success',
        3: 'danger'
      };
      return typeMap[status] || 'info';
    },

    getPhotoTypeText(photoType) {
      const typeMap = {
        'idCardFront': '身份证正面',
        'idCardBack': '身份证反面',
        'personPhoto': '免冠照片',
        'customPhoto': '自定义照片'
      };
      return typeMap[photoType] || photoType;
    }
  }
};
</script>
```

## 五、业务流程设计

### 1. 商品配置流程
1. **管理员配置**：在商品管理页面为特定商品开启照片要求
2. **照片类型配置**：选择需要的照片类型和是否必填
3. **保存配置**：系统保存照片配置到商品表

### 2. 用户下单流程
1. **商品展示**：H5页面显示商品详情和照片要求
2. **照片上传**：用户根据要求上传相应照片
3. **格式验证**：前端验证照片格式、大小等
4. **订单创建**：完成照片上传后创建订单，状态为APPLY(1)，photo_status=PENDING(1)

### 3. 代理商维护流程
1. **查看订单**：代理商在后台查看需要照片审核的订单
2. **照片管理**：可以重新上传或修改照片
3. **提交审核**：确认无误后提交管理员审核，photo_status=PENDING(1)

### 4. 管理员审核流程
1. **待审核列表**：管理员查看所有photo_status=PENDING(1)的订单
2. **照片审查**：审核照片质量和合规性
3. **审核决策**：
   - 通过：photo_status=APPROVED(2)，订单正常流程继续
   - 拒绝：photo_status=REJECTED(3)，返回代理商重新上传
4. **流程继续**：审核通过后订单进入后续发货流程

## 八、文件上传与存储

- **文件大小限制**：单张照片不超过5MB

- **图片质量要求**：建议分辨率不低于800x600像素

- **存储路径**：`/uploads/order_photos/{orderId}/`
- **文件命名**：`{orderId}_{photoType}_{timestamp}.jpg`
- **备份策略**：重要订单照片进行多副本备份

- **内容安全检测**：集成图片内容安全API
- **访问权限控制**：照片仅授权用户可访问
