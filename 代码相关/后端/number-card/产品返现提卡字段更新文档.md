# 叮咚号卡系统产品返现/提卡字段扩展更新文档

## 📋 更新概述

为支持「佣金返现」与「付费提卡」两种业务能力，本次更新在产品表 `t_product` 中新增 `sfyjfx`、`sffftk` 字段，并同步后端实体、接口返回值以及前端管理后台的配置项。默认值均为 0，保证历史商品行为保持不变。

**更新时间**：2025-01-31  
**字段说明**：
- `sfyjfx`：是否参与佣金返现，0-否，1-是。
- `sffftk`：是否需要付费提卡，0-否，1-是。

## 🔧 数据库变更

见升级脚本：`sql/V2.1.5/product_commission_flags.sql`
```sql
ALTER TABLE `t_product`
  ADD COLUMN `sfyjfx` TINYINT(1) NOT NULL DEFAULT 0 COMMENT '是否参与佣金返现：0-否 1-是' AFTER `product_commission`,
  ADD COLUMN `sffftk` TINYINT(1) NOT NULL DEFAULT 0 COMMENT '是否需要付费提卡：0-否 1-是' AFTER `sfyjfx`;

UPDATE `t_product`
SET sfyjfx = 0,
    sffftk = 0
WHERE sfyjfx IS NULL OR sffftk IS NULL;
```
