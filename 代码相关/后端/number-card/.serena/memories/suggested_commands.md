# Suggested Commands

## Frontend (Vue 2 bundles under `代码相关/前端/前端代码`)
- `npm install`
- `npm run dev` – local dev server (e.g., admin console).
- `npm run build:prod` – production build output in `dist/`.
- `npm run lint` – ESLint auto-fix.

## Backend (`代码相关/后端/number-card`)
- `mvn clean package -pl ruoyi-admin -am` – build backend modules.
- `java -jar ruoyi-admin/target/ruoyi-admin.jar` – launch backend locally.
- `mvn test` – run unit/integration tests.

## Utilities
- `git status`, `git diff`, `rg <pattern>`, `ls`, `find` – standard development helpers on macOS (Darwin).
