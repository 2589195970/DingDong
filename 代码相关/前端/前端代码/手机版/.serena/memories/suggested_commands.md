# 常用命令
- `npm install`：安装依赖（uview-ui、crypto-js、echarts）。
- `npx @dcloudio/uni-cli-service dev:<platform>`：使用 uni-app CLI 启动各平台（如 `dev:h5`、`dev:mp-weixin`）。若使用 HBuilderX，可通过 IDE 的“运行到浏览器/小程序模拟器”。
- `npx @dcloudio/uni-cli-service build:<platform>`：打包对应平台产物。
- `npm run lint` 当前未定义，可根据需要补充 ESLint 配置。
- 通用终端：`ls` 查看目录、`rg <pattern>` 搜索、`cat`/`sed` 阅读文件、`npm ls` 检查依赖。
